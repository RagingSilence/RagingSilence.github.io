## 记录一个具体的问题

学习笔记可以从一个小问题开始：这个概念解决什么问题？我为什么会卡在这里？能不能用最小的例子解释清楚？

不必等到完全理解才动笔。把当前的理解和疑问写下来，之后再回来修订。

## 用代码验证理解

例如，用一个短程序观察二分查找的过程：

```python
def binary_search(items, target):
    left, right = 0, len(items) - 1
    while left <= right:
        mid = (left + right) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

print(binary_search([1, 3, 5, 7, 9], 7))  # 3
```

这个例子要求输入序列已经排序。查找区间每次缩小约一半，时间复杂度为 \(O(\log n)\)。

## 给推导留出空间

行内公式可以写作 \(a^2 + b^2 = c^2\)，也可以单独展示公式：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

### 一个可以重复使用的结构

1. 今天学习了什么？
2. 用自己的话，如何解释它？
3. 哪个例子或实验支持这个理解？
4. 还有什么疑问？
5. 下一步准备怎么做？

每次写清一个小问题，笔记就会慢慢积累起来。
